# Personal Portfolio
I build systems that remove repetitive bottlenecks. I'm studying Information Systems in BYU's STEM-designated program, and I'm interested in where data, process and automation meet: finding the manual steps that slow a team down and replacing them with workflows that run on their own.

This portfolio shows that work in three areas:

Organization: spreadsheets and Notion systems that organize data so it's easy to act on, including project dashboards, academic trackers and analysis models. Each one can be downloaded or duplicated.

Automations: n8n workflows and Python pipelines, such as multi-stage outreach engines, MCP-based assistants that let LLMs use tools on their own, and custom scrapers. Each one has a walkthrough of how it works and a workflow file you can import.

Web Apps: coming soon.

I'm looking for roles where I can connect systems and build high-impact workflows for forward-thinking teams. If that sounds like your team, let's connect.
